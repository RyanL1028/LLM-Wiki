# Atomic Number (Proton Number)

**Summary**: The atomic number (Z) is the number of protons in the nucleus of an atom, uniquely defining the element and determining its position in the [[Periodic Table Trends|periodic table]].
**Tags**: #igcse #chemistry
**Created**: 2026-07-18

---

The **atomic number** (also called the **proton number**) is the number of protons found in the nucleus of an [[Atomic Structure|atom]]. It is given the symbol **Z** and is the single most important identifier of an [[Element]] — every element has a unique atomic number, meaning that changing the number of protons changes the element entirely. In a neutral atom, the number of electrons equals the atomic number (since each proton's positive charge is balanced by one electron's negative charge). The atomic number also determines the element's position in the [[Periodic Table Trends|periodic table]] — elements are arranged in order of increasing atomic number from left to right and top to bottom. For example, carbon has Z = 6 (6 protons), oxygen has Z = 8 (8 protons), and sodium has Z = 11 (11 protons). Knowing the atomic number is essential for determining [[Electronic Configuration|electron configuration]], predicting chemical behaviour, and understanding [[Periodic Table Trends|periodic trends]].

---

## The Meaning of Atomic Number

The atomic number (Z) tells you exactly which element you are dealing with:

- **Z = number of protons** in the nucleus of every atom of that element
- **Z = number of electrons** in a neutral atom (since total positive charge must equal total negative charge)
- **Z determines the identity** of the element — if Z changes, the element changes

For example, every atom with Z = 6 is a carbon atom, every atom with Z = 17 is a chlorine atom, and every atom with Z = 79 is a gold atom. There is no exception to this rule.

### Atomic Number and the Periodic Table

The modern [[Periodic Table Trends|periodic table]] is arranged in order of increasing atomic number. This is a fundamental principle:

| Element | Symbol | Atomic Number (Z) |
|---------|--------|-------------------|
| Hydrogen | H | 1 |
| Helium | He | 2 |
| Lithium | Li | 3 |
| Beryllium | Be | 4 |
| Boron | B | 5 |
| Carbon | C | 6 |
| Nitrogen | N | 7 |
| Oxygen | O | 8 |
| Fluorine | F | 9 |
| Neon | Ne | 10 |

### Atomic Number vs Mass Number

The atomic number (Z) is distinct from the [[Mass Number (Nucleon Number)|mass number]] (A), which is the total number of protons plus neutrons in the nucleus. These two numbers are often written together in nuclide notation:

```
  A
   X
  Z
```

For example, ^23_11Na means Z = 11 (11 protons, sodium) and A = 23 (total nucleons). The number of neutrons is found by subtracting: **neutrons = A - Z**.

### Atomic Number in Ions

When an atom forms an [[Ion]], the atomic number does not change — only the number of electrons changes. A Na^+ ion still has Z = 11 (11 protons) but now has only 10 electrons. A Cl^- ion still has Z = 17 (17 protons) but now has 18 electrons. The proton number is what makes sodium sodium and chlorine chlorine, regardless of charge.

## Common Misconceptions

| Misconception | Reality |
|---|---|
| "Atomic number and mass number are the same thing" | Atomic number (Z) is the number of protons only. [[Mass Number (Nucleon Number)|Mass number]] (A) is protons plus neutrons. They are different numbers for all elements except hydrogen-1. |
| "The atomic number tells you the number of neutrons" | The atomic number tells you the number of protons (and electrons in a neutral atom). Neutrons are found by subtracting Z from the mass number A. |
| "If an atom gains electrons, its atomic number changes" | The atomic number (number of protons) never changes during chemical reactions. Only the number of electrons changes when [[Ion|ions]] form. |
| "Elements are arranged by mass in the periodic table" | The modern periodic table is arranged by atomic number (proton number), not atomic mass. This was Mendeleev's key insight refined by Moseley. |
