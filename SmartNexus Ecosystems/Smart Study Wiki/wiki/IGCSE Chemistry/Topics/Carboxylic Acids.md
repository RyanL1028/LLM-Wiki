# Carboxylic Acids

**Summary**: Contain —COOH functional group. Ethanoic acid (CH₃COOH) is a weak acid. React with alcohols to form esters (esterification, H₂SO₄ catalyst).

## Functional Group: —COOH (Carboxyl)

General formula: CₙH₂ₙ₊₁COOH

| Acid | Formula | Notes |
|------|---------|-------|
| Methanoic acid | HCOOH | Found in ant stings |
| Ethanoic acid | CH₃COOH | Vinegar (5% solution) |
| Propanoic acid | C₂H₅COOH | |
| Butanoic acid | C₃H₇COOH | Rancid butter smell |

## Properties

### As Acids
- Carboxylic acids are **weak acids** — they only partially dissociate in water
- CH₃COOH ⇌ H⁺ + CH₃COO⁻ (equilibrium, not complete)
- React with metals, bases, and carbonates like other acids (but more slowly than strong acids)

### Reactions as Acids
- **With metal:** 2CH₃COOH + Mg → (CH₃COO)₂Mg + H₂
- **With base:** 2CH₃COOH + CuO → (CH₃COO)₂Cu + H₂O
- **With carbonate:** 2CH₃COOH + Na₂CO₃ → 2CH₃COONa + H₂O + CO₂

### Esterification
Carboxylic acid + Alcohol ⇌ Ester + Water

CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O
(ethanoic acid + ethanol ⇌ ethyl ethanoate + water)

**Conditions:**
- **Concentrated H₂SO₄** as catalyst
- **Heat** under reflux
- This is a **reversible** reaction (equilibrium)

## Naming Esters
- First part: from the alcohol (e.g., ethyl from ethanol)
- Second part: from the carboxylic acid (e.g., ethanoate from ethanoic acid)
- Methanol + ethanoic acid → METHYL ETHANOATE
- Ethanol + propanoic acid → ETHYL PROPANOATE

## Key Facts
- Carboxylic acids are WEAK acids (partial dissociation)
- Functional group: —COOH
- Esterification requires concentrated H₂SO₄ catalyst + heat
- Naming esters: alcohol part first, acid part second
