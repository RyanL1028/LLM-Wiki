# Periodic Table Trends

**Summary**: Elements arranged by increasing atomic number. Periods are horizontal rows; groups are vertical columns. Properties show periodic trends.

## Structure of the Periodic Table

- **Periods**: Horizontal rows (1–7). Elements in the same period have the same number of electron shells.
- **Groups**: Vertical columns (1–18 or I–VIII). Elements in the same group have the same number of outer shell electrons → similar chemical properties.

## Key Trends

### Across a Period (left → right)
- Metallic character **decreases**
- Atomic radius **decreases** (increased nuclear charge pulls electrons closer)
- Melting/boiling points: increase to Group 4, then decrease
- Oxides change from basic (left) → amphoteric (middle) → acidic (right)

### Down a Group (top → bottom)
- Metallic character **increases**
- Atomic radius **increases** (more electron shells)
- Reactivity: increases for Groups 1–2, decreases for Groups 6–7
- Density generally increases
- Melting/boiling points: decrease for Group 1, increase for Group 7

## Classification of Elements

### Metals (left and centre of table)
- Shiny, malleable, ductile, good conductors
- Form positive ions (cations)
- Form basic oxides

### Non-metals (right of table)
- Dull, brittle, poor conductors
- Form negative ions (anions) or covalent bonds
- Form acidic oxides

### Metalloids/Semi-metals
- Properties intermediate between metals and non-metals
- Examples: Si, Ge, As, Sb, Te

## Group Number = Valence Electrons
- Group 1: 1 outer electron → forms 1+ ions
- Group 2: 2 outer electrons → forms 2+ ions
- Group 13: 3 outer electrons → forms 3+ ions
- Group 16: 6 outer electrons → forms 2− ions
- Group 17: 7 outer electrons → forms 1− ions
- Group 18: 8 outer electrons (full) → unreactive

## Key Facts
- Elements in the same GROUP have the same number of outer shell electrons → similar reactions
- Period number = number of electron shells
- Group number (1–2, 13–18) = number of electrons in the outer shell
- Metals lose electrons; non-metals gain electrons
