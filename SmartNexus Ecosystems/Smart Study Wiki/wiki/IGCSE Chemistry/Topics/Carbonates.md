# Carbonates

**Summary**: Metal carbonates thermally decompose to metal oxide + CO₂ (except Group 1). Limestone cycle: CaCO₃ → CaO → Ca(OH)₂ → CaCO₃. Uses: cement, mortar, lime.

## Thermal Decomposition of Carbonates

Metal carbonate → Metal oxide + Carbon dioxide

### Trend: Stability increases DOWN the group

| Carbonate | Decomposition temperature | Ease of decomposition |
|-----------|--------------------------|-----------------------|
| Na₂CO₃, K₂CO₃ | Very high | Do NOT decompose (bunsen burner cannot reach temp) |
| CaCO₃ | ~825°C | Decomposes with strong heating |
| MgCO₃ | ~350°C | Decomposes easily |
| CuCO₃ | ~200°C | Decomposes very easily (green → black) |
| ZnCO₃ | ~300°C | Decomposes (white → yellow when hot, white when cold) |

**General equation**: MCO₃(s) → MO(s) + CO₂(g)

### Examples:
- CaCO₃(s) → CaO(s) + CO₂(g)
- CuCO₃(s) → CuO(s) + CO₂(g) — green solid → black solid
- Na₂CO₃(s) → **No decomposition** with Bunsen burner

## The Limestone Cycle

```
     CaCO₃ (limestone)
        ↓ + heat (thermal decomposition)
     CaO (quicklime / calcium oxide) + CO₂
        ↓ + H₂O (slaking — exothermic)
     Ca(OH)₂ (slaked lime / calcium hydroxide)
        ↓ + CO₂ (recarbonation)
     CaCO₃ (limestone again) + H₂O
```

**Key reactions:**
1. CaCO₃ → CaO + CO₂ (thermal decomposition)
2. CaO + H₂O → Ca(OH)₂ (slaking — exothermic, hissing sound)
3. Ca(OH)₂ + CO₂ → CaCO₃ + H₂O (limewater test — turns milky)

## Uses

| Substance | Name | Uses |
|-----------|------|------|
| CaCO₃ | Limestone | Building stone, making cement, making glass, neutralising acidic soil |
| CaO | Quicklime | Making Ca(OH)₂, neutralising acidic soil, drying agent |
| Ca(OH)₂ | Slaked lime | Mortar (with sand + water), treating acidic soil, limewater test for CO₂ |
| Cement | CaO + SiO₂ + Al₂O₃ (heated) | Binding material in concrete |
| Concrete | Cement + sand + gravel + water | Construction |

## Key Facts
- Group 1 carbonates (Na₂CO₃, K₂CO₃) do NOT decompose with a Bunsen burner
- More reactive metals have MORE stable carbonates
- CaO + H₂O is EXOTHERMIC (slaking of lime)
- Limewater = Ca(OH)₂(aq) — the classic test for CO₂
