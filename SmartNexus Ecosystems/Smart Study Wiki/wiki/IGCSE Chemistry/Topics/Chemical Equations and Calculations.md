## Balancing Chemical Equations

### Rules
1. Write the correct **formulae** for all reactants and products
2. Count atoms of each element on both sides
3. Adjust **coefficients** (numbers in front) — NEVER change subscripts in formulae
4. Check each element is balanced
5. Add **state symbols**: (s) solid, (l) liquid, (g) gas, (aq) aqueous

**Example**: H₂(g) + ½O₂(g) → H₂O(l) or 2H₂(g) + O₂(g) → 2H₂O(l)

## State Symbols

| Symbol | Meaning | Examples |
|--------|---------|----------|
| (s) | Solid | NaCl(s), CuO(s), CaCO₃(s) |
| (l) | Liquid | H₂O(l), Br₂(l), Hg(l) |
| (g) | Gas | CO₂(g), O₂(g), H₂(g) |
| (aq) | Aqueous (dissolved in water) | NaCl(aq), HCl(aq), NaOH(aq) |

## Ionic Equations

### Method
1. Write the balanced full equation with state symbols
2. Separate all (aq) substances into their ions
3. **Cancel spectator ions** (ions that appear unchanged on both sides)
4. Write the remaining ions as the ionic equation

**Example — Neutralisation:**
- Full: HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)
- Ionic: H⁺(aq) + Cl⁻(aq) + Na⁺(aq) + OH⁻(aq) → Na⁺(aq) + Cl⁻(aq) + H₂O(l)
- Cancel Na⁺ and Cl⁻ (spectators)
- **H⁺(aq) + OH⁻(aq) → H₂O(l)** ← the universal neutralisation equation

**Example — Precipitation:**
- Full: AgNO₃(aq) + NaCl(aq) → AgCl(s) + NaNO₃(aq)
- Ionic: Ag⁺(aq) + Cl⁻(aq) → AgCl(s)

## Half Equations

Show what happens at each electrode during electrolysis or in redox.
- Oxidation at anode: 2Cl⁻ → Cl₂ + 2e⁻
- Reduction at cathode: Cu²⁺ + 2e⁻ → Cu

## Key Formulas

| Formula | Used for |
|---------|----------|
| n = m / Mr | Moles from mass |
| n = c × V (dm³) | Moles from concentration and volume |
| n = V (dm³) / 24 | Moles of gas at r.t.p. |
| % yield = (actual / theoretical) × 100 | Reaction efficiency |
| % purity = (mass of pure / total mass) × 100 | Sample purity |

## Key Facts
- NEVER change subscripts when balancing — only add coefficients
- Spectator ions are removed in ionic equations
- State symbols are REQUIRED in IGCSE answers
- (aq) means dissolved in water, NOT liquid
