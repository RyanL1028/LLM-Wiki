## Content

The [[Periodic Table]] is the chart that lists known elements in a structured layout. In the source lesson, it is introduced as the place where elements with similar properties are grouped together.

The table supports quick lookup of element names and [[Chemical Symbols]]. It also helps students compare element behavior and classify substances.
