# Chemical Symbols

## Content

Each element has a standard symbol used in science writing and formulas. Many symbols use the first letter (for example `H`, `C`, `O`, `N`), while others use two letters (for example `Li`, `Al`, `He`) or historical roots (for example `Au`, `Ag`, `Pb`).

Two formatting rules prevent confusion:

- The first letter is always uppercase.
- If a second letter exists, it is lowercase.

These symbols are essential for reading the [[Periodic Table]] and writing chemical formulae.
