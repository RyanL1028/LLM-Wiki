# 3 The Periodic Table

![](images/9781382063821_graphic_266.jpg)
> **In this chapter, you will:**
> - recall that everything in the Universe is made up of [[Atoms]] of one or more of the 100 or so [[Elements]] that exist
> - understand that each element has its own unique properties, different to the properties of all other elements
> - learn about metal and non-metal elements, and how to work out which are which
> - discover how the elements are organized in the [[Periodic Table]] to show patterns in their properties
> - learn how to use the Periodic Table to make predictions.

> **Think back**
> 1. Gold is a metal element. Describe its properties.
> 2. Write a list of 10 elements.
> 3. Predict which has the higher melting point – oxygen or gold.
> 4. If magnesium and oxygen are combined, what is the name of the compound? A magnesium oxate B magnesium oxygen C magnesium oxide D oxygen manganate

> **Key ideas**
> An element is a substance that cannot be broken down into other substances. It has one type of atom.
> There are about 100 elements.
> Melting point is the temperature at which a substance changes state from solid to liquid.
> [[Acids]] are substances with pH lower than 7. Bases are substances that neutralize acids.
